# [단계 2] 입력 전달과 시간 관리

## 목표와 범위

키·마우스 입력의 수집과 소비, 고정 tick, 실제 시간과 시뮬레이션 시간, 정지·배속을 구현한다. 액션 이름과 키의 연결은 작은 명시적 표로 시작한다. 콤보·보스 행동·설정 UI는 제외한다. 선행: 단계 1.

## 모듈 계약

Input은 tick 사이의 입력을 보관하고 한 번 소비하게 한다. Time은 진행 시간을 제공한다. 행동 Component는 입력과 시간을 읽으며 배속·정지 변경은 명시한 경계에서 적용한다.

## 완료 조건

- [x] 누름·유지·해제와 마우스 변화량을 구분한다.
- [x] tick 사이의 짧은 입력이 누락되지 않고 여러 tick에서 반복 실행되지 않는다.
- [x] 정지·재개·배속에 따른 누적 시간과 이동량을 확인한다.
- [x] 포커스 상실 후 이전 입력이 남지 않는다.
- [x] 낮은 FPS에서 따라잡기 상한과 초과 시간 처리 정책을 문서화한다.

## 학생 질문과 과제

1. 입력 수집과 소비를 왜 나누는가?
2. 렌더 프레임과 고정 tick은 무엇이 다른가?
3. 게임 시간과 실제 시간을 분리하면 무엇을 제어할 수 있는가?

변형 과제: 같은 실제 시간 동안 정상 배속과 절반 배속의 이동 거리를 비교한다.
