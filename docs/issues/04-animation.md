# [단계 4] 모델 원본과 객체별 애니메이션 재생

## 목표와 범위

한 가지 모델 형식과 대표 스킨 모델·클립을 먼저 지원한다. AssetManager의 로딩·공유와 Animator의 재생·반복·완료·기본 블렌딩을 구현한다. 리타게팅·애니메이션 그래프 편집기·여러 임포트 규격은 제외한다. 선행: 단계 3.

## 모듈 계약

모델·클립 원본은 공유하고 재생 시각과 포즈는 객체별로 가진다. Animator가 같은 시뮬레이션 시간 기준으로 포즈를 계산하고 Renderer에 뼈 데이터를 전달한다. 사용할 외부 로더가 필요하면 역할과 의존성을 먼저 문서화한다.

## 완료 조건

- [ ] 실제 모델과 대표 모션이 표시된다.
- [ ] 선택한 클립의 반복·완료·기본 전환이 관찰된다.
- [ ] 정지·배속이 모션 재생에 반영된다.
- [ ] 같은 원본을 쓰는 두 객체의 재생 시각을 독립적으로 바꿀 수 있다.
- [ ] 누락 파일과 지원하지 않는 데이터가 이해 가능한 오류로 보고된다.

## 학생 질문과 과제

1. 모델 원본과 Animator 상태를 왜 분리하는가?
2. 클립의 시간으로부터 뼈 자세와 화면이 어떻게 만들어지는가?
3. 공유 원본을 쓰는 객체 하나를 삭제하면 무엇이 남아야 하는가?

변형 과제: 같은 모델 두 개의 재생 시작 시점을 다르게 설정해 비교한다.
