# [단계 5] 애니메이션 시점과 판정 구간 연결

## 목표와 범위

Sphere·Box 판정체, Layer·Mask, Trigger, 필요한 Raycast와 접촉 결과를 구현한다. 모션의 마커·활성 구간을 판정에 연결한다. 피해량·패링·보스 규칙은 제외한다. 선행: 단계 4.

## 모듈 계약

Animator/Timeline은 이전·현재 재생 위치와 통과한 마커·구간을 제공한다. CollisionWorld는 해당 구간의 판정 후보를 반환한다. 단순히 tick 마지막의 활성 여부만 검사하지 않는다. 곡선 이동을 정확히 검사하지 못하는 경우 지원 범위와 샘플링 정책을 명시한다.

## 완료 조건

- [ ] 입력→모션→판정 활성 구간→접촉 로그가 한 예제로 연결된다.
- [ ] 판정체를 디버그 도형으로 확인할 수 있다.
- [ ] 한 tick에서 활성·비활성 마커를 모두 통과해도 해당 구간을 검사한다.
- [ ] 정지·배속·재생 취소 후 판정이 시간과 맞고 잔존하지 않는다.
- [ ] 같은 공격의 중복 판정 구분에 사용할 식별자를 제공한다.

## 학생 질문과 과제

1. 애니메이션과 판정은 어떤 시간 기준을 공유하는가?
2. 한 tick에서 두 마커를 모두 지나가면 어떻게 처리해야 하는가?
3. 접촉 사실과 피해 결정은 각각 어디의 책임인가?

변형 과제: 판정 구간을 짧게 바꾸고 낮은 FPS에서 누락 여부를 관찰한다.
