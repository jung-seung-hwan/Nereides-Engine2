# [단계 6] 캐릭터와 크라켄의 작은 전투

## 목표와 범위

지금까지 만든 엔진 기능을 이용해 캐릭터 행동 하나와 크라켄 공격 하나를 연결한다. 단순 HP, 전투 종료, 재시작을 제공한다. 다중 페이즈·콤보·복잡한 AI·정교한 HUD·대규모 콘텐츠는 제외한다. 선행: 단계 5.

## 모듈 계약

행동 선택과 피해는 게임용 Component에 둔다. 엔진은 입력·시간·애니메이션·접촉 결과를 제공한다. 게임 규칙 때문에 Renderer나 기본 Collider를 수정해야 한다면 경계를 재검토한다.

## 완료 조건

- [ ] 실제 캐릭터와 크라켄 모델이 같은 장면에 있다.
- [ ] 캐릭터의 행동 하나와 크라켄의 공격 하나가 재생·판정·반응까지 연결된다.
- [ ] 타격 결과와 HP를 최소 텍스트 또는 디버그 출력으로 확인한다.
- [ ] 종료 후 재시작 시 입력·재생·판정·HP가 초기화된다.
- [ ] 구현된 게임 규칙과 임시 수치를 명시한다.

## 학생 질문과 과제

1. 피해량을 CollisionWorld에 넣으면 어떤 결합이 생기는가?
2. 공격을 취소하면 어떤 모듈의 상태를 정리해야 하는가?
3. 다른 적을 추가해도 그대로 사용할 엔진 기능은 무엇인가?

변형 과제: 크라켄 공격 간격 한 값을 바꾸고 엔진 코드는 바뀌지 않는지 확인한다.
