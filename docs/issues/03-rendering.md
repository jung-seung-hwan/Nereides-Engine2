# [단계 3] DX11로 단일 장면 표시

## 목표와 범위

DX11 창 출력, 카메라, 기본 메시·색상·깊이, GameObject 상태의 렌더 전달을 구현한다. 바닥·Player·Kraken은 단순 도형으로 표현한다. 범용 RHI·고급 재질·후처리·씬 에디터는 제외한다. 선행: 단계 2.

## 모듈 계약

Renderer는 장치와 GPU 리소스를 관리한다. Scene의 위치·카메라·표시 데이터를 작은 명시적 구조로 전달받는다. 게임 행동 결정은 Renderer에 넣지 않는다.

## 완료 조건

- [ ] 바닥과 두 객체가 카메라·깊이를 적용해 표시된다.
- [ ] Transform 변화가 화면 위치에 반영된다.
- [ ] 창 크기 변경과 최소화·복원에 대응한다.
- [ ] 초기화·종료 시 GPU 리소스 소유와 정리를 설명한다.

## 학생 질문과 과제

1. GameObject의 위치가 화면에 도달하는 경로는 무엇인가?
2. 카메라와 Renderer는 어떤 관계인가?
3. CPU 원본 데이터와 GPU 리소스의 소유자는 누구인가?

변형 과제: 카메라 위치를 바꾸고 같은 월드 좌표의 객체가 어떻게 보이는지 설명한다.
