# [단계 4-2] Animator 재생과 스키닝

## 목표와 범위

4-1에서 읽은 모델 원본의 클립을 객체마다 따로 재생한다. Animator 컴포넌트가 재생·반복·완료·클립 바꾸기를 맡고, tick 안의 애니메이션 단계에서 자세와 뼈 행렬을 계산한다. 뼈 행렬은 RenderFrame의 그리기 항목에 실려 셰이더가 정점을 뼈에 붙여 움직인다(스키닝). 정지·배속이 재생에 그대로 반영된다. 창 모드에서 Space를 누르면 Player가 클립을 한 번 재생하고 Kraken은 반복 재생한다. 선행: 단계 4-1.

번호 이력: 2026-11-09 SceneManager를 4-2로 끼우며 잠시 4-3이었다가, 같은 날 학생이 SceneManager를 단계 6 뒤로 미뤄 다시 4-2다(이슈 #19).

- 포함: 뼈 계층·역바인드 행렬·클립 읽기(4-1 로더 확장)와 좌표 변환, 정점의 뼈 번호·가중치, Animator(재생 시각, 반복, 완료, 바로 바꾸기, tick 기록, 뼈 행렬), 스키닝 셰이더, Space로 재생, 시험 모델의 둘째 클립, CPU 시험.
- 제외: 포즈 보간(50Hz 그대로), 섞는 전환, 리타게팅, 애니메이션 그래프, 마커·판정 구간(단계 5), STEP·CUBICSPLINE 보간, 모프.

## 모듈 계약

- 모델·클립·뼈 원본은 AssetManager가 공유하고, 재생 시각·자세·뼈 행렬·tick 기록은 Animator가 객체마다 가진다(장면 상태 규칙: 장면에 속한 상태는 Scene 안의 객체·컴포넌트에 둔다).
- Animator는 tick 안, Scene.FixedUpdate 뒤의 애니메이션 단계에서 `FixedDeltaTime()`만큼 진행한다. Update에서 진행하지 않는다. 그래야 단계 5의 판정과 같은 시계를 쓴다.
- 애니메이션 단계는 Component의 가상 함수 `AdvanceAnimation()`으로 Animator에 닿는다. PlayerControl·ModelRenderer는 장면을 만들 때 Animator 주소를 받는다.
- `Play` 요청은 같은 tick의 애니메이션 단계에서 먹는다. Animator는 tick마다 재생 구간의 시작·끝, 시작했는지, 되감겼는지, 끝났는지를 남긴다. 구간 끝을 넣는 규칙은 설계 문서에 있다. 단계 5의 마커 판정이 그대로 쓴다.
- 뼈 행렬(스키닝용, 뼈의 모델 공간 위치)은 tick 안에서 Animator가 계산해 둔다. 수집 함수는 읽기만 한다.
- 정점 형식에 뼈 번호 4개와 가중치 4개를 더한다. 셜록과 같은 모양이다. 뼈가 없는 정점은 가중치가 모두 0이고 셰이더가 옮기지 않는다.
- 뼈·클립도 4-1의 X 뒤집기 규칙을 따른다(이동 x 부호, 사원수 y·z 부호, 역바인드 행렬 S·M·S). 시험 모델의 둘째 클립 "swing"이 변환 누락을 잡는다.

학생이 정한 것(2026-11-09): 포즈 보간은 50Hz 그대로, Animator를 찾는 길은 Component 가상 함수, Animator에 닿는 길은 만들 때 주소 넘기기, 클립 바꾸기는 바로, Space로 재생을 보인다.

## 완료 조건

- [ ] 창 모드에서 Kraken이 클립을 반복 재생하고, Space를 누르면 Player가 클립을 한 번 재생한다.
- [ ] 정지·배속·긴 프레임이 재생에 반영된다(CPU 시험).
- [ ] 같은 원본을 쓰는 두 객체의 재생 시각이 따로 간다.
- [ ] 모든 뼈가 기본 자세일 때 스키닝 결과가 4-1의 화면과 같다(뼈 행렬이 단위 행렬).
- [ ] tick마다 남긴 시작·끝 위치, 시작·되감김·끝 표시를 CPU 시험이 확인한다.
- [ ] 뼈·클립 좌표 변환을 빠뜨리면 실패하는 시험이 있다("swing").
- [ ] 뼈 없는 정점(받침·바닥)이 어떤 클립에서도 움직이지 않는다.
- [ ] 설계 검증 보고서(재생 전환)의 조건 3개(좌표 변환과 시험, 뼈 없는 정점, 입력 → 재생 → tick → 기록)가 설계 문서에 적혀 있다.

## 학생 질문과 과제

1. Space를 누른 tick에서 Player의 재생이 시작되기까지 거치는 함수를 순서대로 적고, 그 tick의 기록(`start`, `end`, `started`)이 어떤 값인지 설명하라.
2. 창을 최소화하면 Kraken의 재생이 멈춘다. Animator 코드에는 정지를 검사하는 줄이 없다. 어디서 멈추는가?
3. 받침(뼈 없는 정점)은 어떤 클립에서도 움직이지 않는다. 정점 형식, 로더, 셰이더에서 그 이유를 찾아 설명하라.

변형 과제: Player의 공격 클립을 "swing"으로 바꾸고, 재생이 끝난 뒤 화살표가 어느 자세에 멈추는지와 그다음 Space에서 어떻게 시작하는지 관찰해 이유를 설명한다.
