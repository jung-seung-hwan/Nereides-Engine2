# [단계 0] 전체 구조와 호출 순서가 보이는 실행 골격

## 목표

엔진 각 모듈의 역할과 관계를 먼저 이해한다. [구조 문서](../architecture.md)를 기준으로 가짜 기반 모듈을 호출하는 작은 콘솔 프로그램을 만든다.

## 범위

Application의 명시적인 함수 호출로 전체 실행 순서를 보여준다. 입력·시간·객체·애니메이션·충돌·렌더는 placeholder로 표시한다. Scene·GameObject·Component 실제 구현은 단계 1로 남긴다. 실제 DX11·고정 tick·애니메이션·충돌·게임 규칙은 제외한다. 선행 이슈는 없다.

## 완료 조건

- [x] 목표 구조와 이번 단계 구현 범위를 구분하고 호출 순서 그림과 코드가 일치한다.
- [x] 각 프레임에서 Input → Time → Objects → Animation → Collision → Render가 출력된다.
- [x] 정해진 횟수 실행 후 정상 종료하고 정리 수명을 설명한다.
- [x] 빌드·실행 명령과 실제 출력 예시를 기록했다.
- [x] 없는 기능의 로그를 `placeholder`로 표시했다.

## 학생 질문과 과제

3. 실제 입력 모듈은 다음 단계에 어떤 데이터를 전달해야 하는가?
