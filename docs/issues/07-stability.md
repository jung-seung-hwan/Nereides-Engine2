# [단계 7] 반복 실행과 경계 상황 검증

## 목표와 범위

프로토타입을 재현 가능한 절차로 검증하고 실행 패키지와 알려진 제한을 정리한다. 새 전투 기능이나 엔진 범용화를 추가하지 않는다. 선행: 단계 6.

## 모듈 계약

재시작은 입력·행동·애니메이션·판정 상태와 객체 수명을 정해진 순서로 정리한다. 오류 보고는 원인을 추적할 정보를 제공한다. 성능 측정은 실제 사용한 장면·해상도·구성을 기록한다.

## 완료 조건

- [ ] 반복 재시작, 정지·재개, 포커스 상실·복원, 낮은 FPS를 검증한다.
- [ ] 오류 재현 조건과 수정 범위를 해당 모듈에 연결해 기록한다.
- [ ] 실행 파일의 필요한 리소스·라이브러리·실행 방법을 정리한다.
- [ ] 깨끗한 배포 폴더에서 실행하고, 시험하지 못한 다른 PC 조건은 미검증으로 남긴다.
- [ ] 성능 수치에 장면·측정 방법을 기록하고 작은 시험을 전체 성능 달성으로 표현하지 않는다.

## 학생 질문과 과제

1. 재시작에서 어떤 모듈의 상태를 어떤 순서로 초기화하는가?
2. 낮은 FPS의 문제를 렌더와 시간·판정 문제로 어떻게 구분하는가?
3. 실행 환경 문제와 엔진 코드 문제를 구분할 증거는 무엇인가?

변형 과제: 경계 상황 하나를 직접 선택해 재현 절차와 예상·실제 결과를 작성한다.
